# FrontEnd-Developer-Practical-Assessment
A modern, responsive user management dashboard web application built with HTML, CSS, JavaScript, and Bootstrap 5. It features a collapsible navigation menu, a categorized sidebar layout, a responsive data table, and an interactive filter drawer system with real-time search and inline editing capabilities.
